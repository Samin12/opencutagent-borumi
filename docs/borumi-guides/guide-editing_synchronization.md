# Screen synchronization

Use this guide when narration and screen content are in separate edit sets.

1. Trim the narration edit set first, targeting only its grouped camera and microphone layers.
2. Reread the timeline and transcript.
3. Inspect the independent screen source across the affected range. Match visible actions to the
   retained narration cues.
4. Trim only the screen layer so each action appears at or just before its spoken cue.
5. Verify the render at each affected cue before committing. Clean joins alone do not prove
   synchronization.

Never apply narration-derived ranges to an independent screen layer.
