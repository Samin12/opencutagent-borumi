# Use cases

The Borumi MCP can help with several video-production workflows:

- **Script ideation and import:** Develop an idea, write and refine the Script, organize it into
  Scenes, and import it into Borumi.
- **Video editing:** Review recorded content and refine the video.
- **Export:** Export the finished video for its intended destination.
- **Supporting content:** Create YouTube descriptions, thumbnails, social posts, and other content
  based on the video.
