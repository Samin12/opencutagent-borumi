# Update a Text Overlay Segment

Text overlay updates target a persisted `text_overlay` Segment by `segment_id`.

- Before applying or replacing the text style, retrieve `editing_segment_text_overlay_templates` and use the closest built-in template as the starting point.
- Include `type`, `segment_id`, and a non-empty `properties` patch.
- Send only the properties that need to change. Use `null` only when the schema permits resetting that property.
- `text_size` is measured in 1080p reference pixels, not as a ratio. Setting it to `null` restores the default of `80`.
- `fixed` sizing uses `x_ratio`, `y_ratio`, `width_ratio`, and `height_ratio` as the overlay rectangle.
- `hug` sizing measures the rendered text and ignores `width_ratio` and `height_ratio`. Its `x_ratio` is a left, center, or right anchor according to `alignment`; `y_ratio` is the top edge.
- Omit `font_families` to use the default stack. If a specific font is required, use a concrete installed family rather than a generic family such as `sans-serif`.
